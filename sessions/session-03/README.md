# Session 3: live demo

1. Extract the ZIP to a writable folder (do not run inside the archive).
2. Open `session-03.Rproj` in RStudio, or set the R working directory to this folder.
3. Run `source("setup.R")` once; this needs internet access to install missing packages.
4. Run `source("demo.R")`, or execute its sections alongside the instructor.

All examples are complete and use synthetic data. Each session is independent;
no previous session output, credentials, downloads, or classroom tasks are needed.
R and RStudio should already be installed. Session 1 uses package build tools
(Rtools on Windows, Xcode command line tools on macOS) for package checks.

the JnJ mini-series by Daniel Sabanés Bové, separate from the adapted slide examples.
