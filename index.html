Good Software Engineering Practice for R Packages

A four-session mini-series for JnJ (online), taught in English by Daniel Sabanés Bové. Learn how to build reliable R packages through presentations and live demos. Participants can execute the completed examples on their own laptop alongside the instructor.

Before joining

Experience writing R functions is recommended. Install R and RStudio. For session 1, install Rtools on Windows or the macOS build tools as appropriate.

Download and extract the ZIP for your session to a writable folder. Open the included .Rproj file and run source("setup.R") once before joining. This installs only the packages needed for that demo and requires internet access. Then run source("demo.R"), or execute its sections alongside the instructor. For session 3, source("launch-app.R") opens the Shiny app; stop it with Escape in RStudio or Ctrl+C in a terminal.

Each download is self-contained, with completed code, synthetic data generated locally, a README, and its license. No code from a previous session is required. Session 4 includes an optimization demo; AI best practices are covered in the slides.
